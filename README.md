This repo lists the constraints on the sterile neutrino mixing with the three active neutrino flavours of the Standard Model, :math:`|U_{eN}|^2`, :math:`|U_{\mu N}|^2` and :math:`|U_{\tau N}|^2`, 
as a function of the sterile neutrino mass :math:`m_{N}`. These constraints were originally collected in the paper [1912.03058](https://arxiv.org/abs/1912.03058) and hosted at the [webpage](https://www.hep.ucl.ac.uk/~pbolton/).
