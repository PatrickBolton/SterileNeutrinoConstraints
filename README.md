# Sterile Neutrino Constraints

This repository lists the current constraints and future sensitivities on the active-sterile mixing between a heavy neutral lepton, $N$, and the three active neutrino flavours of the Standard Model, $\nu_e$, $\nu_\mu$ and $\nu_\tau$. Limits on $|U_{eN}|^2$, $|U_{\mu N}|^2$ and $|U_{\tau N}|^2$ are given as a function of $m_{N}$. These constraints were originally collected in the paper [1912.03058](https://arxiv.org/abs/1912.03058) and hosted at the [webpage](https://www.hep.ucl.ac.uk/~pbolton/). This repository provides an updated database of constraints.
